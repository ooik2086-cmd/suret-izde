# 🚗 AvtoUsta — авто шеберлерін табатын маркетплейс

**Миссия:** Қазақстанның кез келген нүктесіндегі автокөлік иелері мен білікті
автожөндеу мамандарын бір платформада жылдам әрі сенімді байланыстыру.

Telegram бот (aiogram v3). Екі **бөлек рөл**, әрқайсысы өз тіркелуімен:

| 🙋 Клиент (көлік иесі) | 🛠 Шебер / СТО |
|---|---|
| Шебер іздеу (мамандық + қала) | Профиль: аты, қала, телефон, мамандық, түрі |
| 🆘 Жолдағы көмек (қаладағы шеберлер) | Рейтинг, TOP-қа шығу, жазылым |
| Өтінім қалдыру *(келесі кезең)* | Жаңа өтінімдерді көру *(келесі кезең)* |

> Бір адам рөлді **«🔄 Рөлді ауыстыру»** арқылы өзгерте алады.

## 1. Жергілікті іске қосу

```bash
cd avtousta
pip install -r requirements.txt
export BOT_TOKEN=123456:ABC...     # @BotFather-дан
# export DATABASE_URL=postgres://... # міндетті емес (болмаса SQLite)
python bot.py
```

`BOT_TOKEN` жоқ болса бот ескертіп тоқтайды.

## 2. Баптаулар (env)

| Айнымалы | Әдепкі | Сипат |
|---|---|---|
| `BOT_TOKEN` | — | **Міндетті.** Telegram бот токені |
| `DATABASE_URL` | — | Render Postgres (болмаса жергілікті SQLite) |
| `ADMIN_ID` | 0 | Әкімші ID — жаңа шебер тіркелгенде хабар келеді |
| `DEFAULT_LANG` | `kz` | Әдепкі тіл (`kz`/`ru`) |
| `COMMISSION_PCT` | 7 | Тапсырыс комиссиясы (%) — келесі кезеңде |
| `SEARCH_PAGE_SIZE` | 5 | Іздеуде бір рет көрсетілетін шебер саны |
| `PORT` | 8080 | Render health сервер порты |
| `DB_PATH` | `avtousta/avtousta.db` | SQLite жолы |

> ⚠️ Тегін SQLite Render қайта іске қосылғанда **өшеді**. Деректі сақтау үшін
> Render Postgres қосып, `DATABASE_URL` беріңіз (тұрақты).

## 3. Render-ге деплой

Түбірдегі `render.yaml`-да `avtousta` сервисі бар (rootDir: `avtousta`).
Бот long-polling, әрі `$PORT`-та health сервер ашады (тегін web-сервис үшін).

---

## 💰 Монетизация (бизнес-модель)
1. **Комиссия** — сәтті тапсырыстан 5–10% (`COMMISSION_PCT`).
2. **TOP/жарнама** — шебер профилін іздеуде жоғары шығару (`config.PROMOTIONS`).
3. **Жазылым** — шеберге айлық/жылдық тариф, шектеусіз тапсырыс (`config.MASTER_SUBSCRIPTIONS`).

Төлем — **Telegram Stars** (aibot-тағыдай, банк қажет емес).

---

## 🗺 Даму кезеңдері
- **1-кезең (қазір):** рөл жүйесі + екі бөлек тіркелу/профиль + санат/қала бойынша шебер іздеу + рейтинг негізі ✅
- **2-кезең:** геолокация (шебер координаталары) → нақты «ең жақын шебер»
- **3-кезең:** өтінім ағыны — клиент ақауды (фото/видео) сипаттайды → шеберлер баға ұсынады
- **4-кезең:** тапсырыс статусы + пікір/жұлдыз қою
- **5-кезең:** Telegram Stars төлемі (комиссия/TOP/жазылым) + модерация панелі
