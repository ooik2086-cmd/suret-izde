# Авто Кликер (Android)

Рекламасыз, қарапайым авто кликер. Ойында (немесе кез келген қосымшада)
экранның белгілі бір нүктесін автоматты түрде басып тұрады.

## Мүмкіндіктер
- 🖱️ Қалқымалы тінтуір белгісі — қолмен қалаған жерге сүйреп қоюға болады
- ◀ ▶ Белгіні оңға-солға жылжытатын түймелер
- ⚡ Жылдамдық реттегіш: 2 секундта 1 рет ↔ секундына ~100 рет
- ▶ СТАРТ / СТОП
- 🚫 Реклама жоқ

## Қолдану
1. Қосымшаны ашып, **Overlay рұқсатын** беріңіз
2. **Accessibility** қызметін қосыңыз («Авто Кликер»)
3. **Бастау** басыңыз — экранда тінтуір белгісі шығады
4. Белгіні басатын жерге қойып, жылдамдықты таңдап, **СТАРТ** басыңыз

## Құрастыру
GitHub Actions автоматты түрде APK жасайды (`.github/workflows/build-autoclicker.yml`).
Жергілікті құрастыру: `cd autoclicker && gradle assembleDebug`
